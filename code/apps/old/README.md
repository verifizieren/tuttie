# First prototype (kept for reference)

The first working version: the assistant goes to the businesses itself, and everything it
does is shown with seals.

- `console/`: chat (left) and the signed "behind the scenes" timeline (right). Open `/old/console/`.
- `wallet/`: the phone page for approvals (`/old/wallet/`); its QR code is in the console
  under **Phone**.

It still runs on the real backend (registry, nodes, assistant). The new Tuttie wallet is
`apps/wallet/`.
